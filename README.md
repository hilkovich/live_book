# Проект "Live book ребенка"

## Описание
Телеграм-бот, через который пользователь может загрузить детские фотографии и на выходе получить книгу-альбом, сгенерированный искусственным интеллектом. Книга-альбом включает в себя историю в виде текстовой информации в формате рассказа разного жанра и сюжета (приключения, комикс, будущая профессия, сказка и т.д.), описание моментов, которые происходят на фотографиях, а также вставки самих фотографий. Книга-альбом дополняется каждый раз в зависимости от загруженного фотоматериала.

Дает возможность сохранить как можно больше памятных и значимых моментов из жизни ребенка, возможность всегда вернуться к важным событиям и датам, поделиться историей в социальных сетях или в мессенджерах, распечатать книгу-альбом в красивом переплете.

## Установка
Сервис можно запустить с помощью Docker Compose.

1. Склонируйте репозиторий проекта:
```
git clone https://github.com/hilkovich/live_book.git
```
2. [Зарегистрируйте](https://core.telegram.org/bots#how-do-i-create-a-bot) телеграм бота и сохраните токен.

3. [Создайте каталог](https://yandex.cloud/ru/docs/resource-manager/operations/folder/create) в Yandex Cloud и сохраните id.

4. [Создайте API ключ](https://yandex.cloud/ru/docs/iam/operations/api-key/create) и сохраните его.

5. Создайте файл **.env** в корневом каталоге проекта и укажите переменные окружения:
```
TG_BOT_TOKEN="<tg_token>"
YANDEX_ID_CATALOG="<id_catalog>"
YANDEX_API_KEY="<api_key>"

POSTGRES_USER="<username>"
POSTGRES_PASSWORD="<password>"
POSTGRES_HOST="postgres"
POSTGRES_PORT=5432
POSTGRES_DATABASE="postgres"

RABBIT_USER="<username>"
RABBIT_PASSWORD="<password>"
RABBIT_HOST="rabbitmq"
RABBIT_PORT=5672
```
6. Запустите сервис с помощью Docker Compose.
```
docker-compose up --build
```
